# Use identity files and an auth.json symlink

Codex Auth Manager stores each identity as `$CODEX_HOME/codex-auth-manager/<identity slug>.json` and makes Codex use one by replacing `$CODEX_HOME/auth.json` with a relative symlink to the active identity file. This keeps v1 simple and recoverable: `cam list` can scan identity files directly, no metadata registry is needed, and switching identities only changes the `auth.json` link. The CLI exposes `status`, `list`, `capture`, `use`, and `detach`, using `identity` language instead of `profile`, `account`, or `slot` to avoid conflicting with Codex concepts and to describe the user-facing auth choice.
